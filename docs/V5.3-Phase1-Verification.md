### 1.5 RLS 策略 ❌ 风险项

**问题：** `supabase/schema.sql` 中 **没有** `memory_photos` 表的定义和 RLS 策略。

`schema.sql` 的注释声称"12 张数据表 + 3 张关联表 = 15 张表"（第 569 行），但实际上以下表均未在 schema 中定义：
- `memories` 表
- `memory_photos` 表
- `countdowns` 表

这些表可能通过 Supabase Dashboard 直接创建，因此其 RLS 状态无法从源代码验证。

**建议：** 在 Supabase Dashboard 中确认以下内容：
```sql
-- 检查表是否存在
SELECT table_name FROM information_schema.tables
WHERE table_name IN ('memories', 'memory_photos', 'countdowns');

-- 检查 RLS 状态
SELECT tablename, rowsecurity FROM pg_tables
WHERE tablename IN ('memories', 'memory_photos', 'countdowns');
```

并确保为 `memory_photos` 添加 RLS 策略：
```sql
ALTER TABLE public.memory_photos ENABLE ROW LEVEL SECURITY;

CREATE POLICY "memory_photos_select" ON public.memory_photos FOR SELECT
  USING (EXISTS (SELECT 1 FROM public.memories WHERE id = memory_photos.memory_id AND user_id = auth.uid()));

CREATE POLICY "memory_photos_insert" ON public.memory_photos FOR INSERT
  WITH CHECK (EXISTS (SELECT 1 FROM public.memories WHERE id = memory_photos.memory_id AND user_id = auth.uid()));

CREATE POLICY "memory_photos_delete" ON public.memory_photos FOR DELETE
  USING (EXISTS (SELECT 1 FROM public.memories WHERE id = memory_photos.memory_id AND user_id = auth.uid()));
```

CREATE TABLE IF NOT EXISTS public.memory_photos (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  memory_id UUID NOT NULL REFERENCES public.memories(id) ON DELETE CASCADE,
  storage_path TEXT NOT NULL,
  url TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. 启用 RLS
ALTER TABLE public.memory_photos ENABLE ROW LEVEL SECURITY;

-- 3. 添加 RLS 策略
CREATE POLICY "memory_photos_select" ON public.memory_photos FOR SELECT
  USING (EXISTS (SELECT 1 FROM public.memories WHERE id = memory_photos.memory_id AND user_id = auth.uid()));

CREATE POLICY "memory_photos_insert" ON public.memory_photos FOR INSERT
  WITH CHECK (EXISTS (SELECT 1 FROM public.memories WHERE id = memory_photos.memory_id AND user_id = auth.uid()));

CREATE POLICY "memory_photos_delete" ON public.memory_photos FOR DELETE
  USING (EXISTS (SELECT 1 FROM public.memories WHERE id = memory_photos.memory_id AND user_id = auth.uid()));
