# V5.3 Phase 1 — 问题分析与修复方案

## 一、大事记功能修复

### 问题定位
- **MemoryTimeline.vue**: 当前仅支持填写图片URL（`image_urls` textarea），无文件上传功能
- **MemoryRepository.ts**: 无Storage上传逻辑，仅保存URL字符串数组
- **Database types**: `memories`表使用`image_urls: string[]`字段存储URL列表

### 涉及文件
- `src/pages/MemoryTimeline.vue` — 修改：增加图片上传UI和逻辑
- `src/repositories/MemoryRepository.ts` — 修改：增加图片上传/删除函数
- `src/stores/memory.ts` — 修改：增加memory_photos相关逻辑
- `src/types/database.ts` — 修改：新增`memory_photos`表类型

### 修改方案
1. 在database.ts中新增`memory_photos`表类型定义
2. 在MemoryRepository中新增uploadMemoryPhoto、fetchMemoryPhotos、deleteMemoryPhoto函数（参考DiaryPhotoRepository的模式）
3. 修改MemoryTimeline.vue：
   - 图片链接输入框改为文件上传区域
   - 上传时调用`supabase.storage.from('photos').upload()`
   - 路径格式：`{userId}/memory/{memoryId}/{timestamp}.{ext}`
   - 显示已上传图片的缩略图，支持删除
4. 删除时同步删除Storage文件

### 8.2 底部导航优化

### 问题定位
- **MobileLayout.vue**: 使用emoji作为导航图标（🏠📋📖👤）

### 涉及文件
- `src/layouts/MobileLayout.vue` — 修改navItems图标
- `src/components/ui/AppIcon.vue` — 已有home/work/book/people图标

### 修改方案
使用AppIcon组件替换emoji：
- 首页：`home` (线性) → `home` (填充色)
- 工作：`briefcase` (线性) → `briefcase` (填充色)  
- 日记：`book` (线性) → `book` (填充色)
- 我的：`people` (线性) → `people` (填充色)

通过active状态切换图标style（色彩填充）实现类似Apple/微信读书的效果：
- 未选中：stroke="currentColor"（线性）
- 选中：fill="currentColor"（填充色版本）

或者使用AppIcon传入不同name：
- 未选中时name直接使用
- 选中时name添加"-filled"后缀并渲染对应填充图标
