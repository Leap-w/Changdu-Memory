## 第一部分：项目整体概况

### 1.1 基本信息

| 项目 | 值 |
|------|-----|
| 名称 | 昌都记忆 (Changdu Memory) |
| 版本 | v5.1.4 |
| 定位 | 个人数字记录平台 — 支教志愿者个人档案系统 |
| 仓库 | `https://github.com/Leap-w/Changdu-Memory` |
| 部署 | Vercel (项目名: `changdu-memory`) |
| 线上地址 | `https://changdu-memory.vercel.app` |

### 1.2 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | Vue 3 (Composition API + `<script setup>`) | ^3.5.18 |
| 构建工具 | Vite 6 | ^6.3.5 |
| 语言 | TypeScript | ~5.8.3 |
| 路由 | Vue Router 4 (history mode) | ^4.5.1 |
| 状态管理 | Pinia | ^2.3.1 |
| UI 库 | Naive UI (表单/日期选择/modal/消息提示) | ^2.41.0 |
| 后端服务 | Supabase (Auth + PostgreSQL + Storage) | ^2.49.4 |
| PWA | vite-plugin-pwa | ^0.21.2 |
| 样式方案 | CSS 自定义属性 (100+ 设计令牌) | — |
| 代码质量 | ESLint 10 + Prettier 3 + vue-tsc | — |

### 1.3 系统架构

```
用户 (Browser)
  │
  ├─ index.html (暗色模式防闪烁脚本 + PWA manifest)
  │
  ├─ main.ts (Vue → Pinia → Router → Auth Init → mount)
  │     │
  │     └─ src/App.vue
  │           ├─ /login → 全屏 Login.vue (不套外壳)
  │           └─ 其他路由 → AppLayout.vue (统一外壳)
  │                 ├─ 顶部悬浮胶囊导航 (毛玻璃 + 导航链接 + 用户头像)
  │                 ├─ 主内容区 (max-width: 1200px 居中)
  │                 └─ 移动端底部导航 (5栏, SVG 线性/填充图标切换)
  │
  ├─ Pinia Stores (15个)
  ├─ Repositories (15个)
  └─ Supabase Cloud
```
